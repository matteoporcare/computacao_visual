# Computação Visual?

Para mim, Computação Visual é a área que estuda como os computadores interpretam, processam e geram imagens a partir de código e dados. Como tenho pouca experiência no assunto e minha bagagem é maior em back-end, vejo a disciplina como uma oportunidade de entender o que acontece nos bastidores dessa manipulação visual.

Acredito que veremos tópicos como processamento de imagem, visão computacional e algoritmos de renderização, conectando conceitos matemáticos à prática do desenvolvimento de software.
